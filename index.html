아이폰 잠금화면 위젯

  1. 앱스토어에서 무료 앱 Scriptable을 설치해요.
  2. 스크립트가 2개예요. 각각 복사 버튼을 누르고, Scriptable에서 ＋ → 붙여넣기 → 맨 위 제목을 눌러 이름을 정확히 바꾸고 Done.
    · 칼로리 원형 위젯 → 이름 Macho
    · 탄단지 막대 위젯 → 이름 MachoBar
  3. 잠금화면을 길게 누르기 → 사용자화 → 잠금화면 → 시계 아래 위젯 칸 → Scriptable 직사각형 2개 추가 → 각 위젯을 눌러 Script를 왼쪽 Macho, 오른쪽 MachoBar로 선택. (Parameter 칸은 비워 두세요)
  4. 아래 스위치를 켜면 오늘 화면에 잠금화면에 반영 버튼이 생겨요. 누르면 Scriptable이 잠깐 열렸다가 숫자를 저장해요. 왼쪽 위 ◀ Macho를 눌러 돌아오면 돼요.
위젯 모양 미리보기

위젯 숫자가 바뀌는 시점은 아이폰이 정해서, 반영 후 보통 몇 분 안에 바뀌어요.

잠금화면 알림 실험

오늘 섭취 현황을 알림으로 띄워 잠금화면에서 볼 수 있게 합니다. 기록할 때마다 갱신됩니다. 안드로이드(크롬)에서 가장 잘 동작하고, 아이폰은 홈 화면에 추가한 뒤에만 가능합니다.
